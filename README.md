# EarthScope

EarthScope - учебный React + Vite проект для просмотра природных событий по всему миру. Приложение объединяет данные о землетрясениях USGS и природных событиях NASA EONET на интерактивной карте.

## API и источники данных

- [USGS Earthquake Feeds](https://earthquake.usgs.gov/earthquakes/feed/v1.0/) — оперативные ленты землетрясений.
- [USGS FDSN Event API](https://earthquake.usgs.gov/fdsnws/event/1/) — исторические запросы по землетрясениям.
- [NASA EONET API v3](https://eonet.gsfc.nasa.gov/docs/v3) — категории и записи природных событий.

Для карты используются [Leaflet](https://leafletjs.com/), стили Stadia Maps/OpenMapTiles и данные OpenStreetMap с обязательной атрибуцией.

## Установка и запуск локально

Установить зависимости:

```bash
npm install
```

Запустить dev-сервер:

```bash
npm run dev
```

После запуска открыть адрес, который выведет Vite. Обычно это:

```text
http://127.0.0.1:5173/
```

## Публикация на GitHub Pages

В проект уже добавлен workflow `.github/workflows/deploy.yml`. Он автоматически запускается после push в ветку `main`.

1. Создайте репозиторий на GitHub и добавьте remote:

```bash
git remote add origin https://github.com/USERNAME/REPOSITORY.git
```

2. Отправьте ветку `main`:

```bash
git branch -M main
git push -u origin main
```

3. На GitHub откройте `Settings → Pages` и выберите `GitHub Actions` как источник публикации.

После успешного workflow сайт будет доступен по адресу:

```text
https://USERNAME.github.io/REPOSITORY/
```

Имя репозитория автоматически используется как base path Vite во время сборки на GitHub Actions.

## Основные возможности

- Live-режим за последние 24 часа, 7 или 30 дней.
- History-режим с выбором периода UTC до 90 календарных дней.
- Фильтры по категориям, названию или региону, магнитуде USGS и статусу NASA.
- Карта Leaflet с точками, полигонами, кластерами, выбором стиля и подсветкой выбранного события.
- Cinematic SVG-иконки для землетрясений, пожаров, штормов, вулканов, наводнений и других событий.
- Карточка события с источником, наблюдениями, статусом, магнитудой, глубиной и ссылкой на исходную запись.
- History Replay с кнопками Play/Pause, Reset, ручной перемоткой, длительностью от 20 до 600 секунд и текущей статистикой.
- Состояния загрузки, пустого результата, ошибки, частичной загрузки и повторной попытки.

Для землетрясений используется порог M4.5+. Исторические запросы разбиваются на небольшие интервалы, а повторяющиеся записи объединяются по ID с сохранением наблюдений в разные даты. Replay использует реальные наблюдения и не отправляет новый API-запрос на каждом кадре анимации

Исторические данные NASA могут быть неполными для отдельных категорий и периодов. Если слой Stadia Maps недоступен, карта автоматически переключается на OpenStreetMap
