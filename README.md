# EarthScope

Учебный React + Vite проект для просмотра природных событий.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно http://127.0.0.1:5173/).

Загружаются землетрясения USGS M4.5+ за сутки, события NASA EONET за 7 дней и категории NASA. События показаны на карте точками и полигонами. Нажатие на событие в списке или на карте открывает карточку с датой, источником, категорией, магнитудой и глубиной, если эти данные есть. Для события с несколькими наблюдениями на карте также показываются его прежние датированные положения.

В правом верхнем углу карты можно сравнить пять подложек: яркую Alidade Bright, природную Outdoors, рельефную Stamen Terrain, акварельную Stamen Watercolor и спокойную Alidade Smooth. Если тайлы выбранной карты не загрузятся, автоматически включится OpenStreetMap. Для локальной разработки ключ Stadia не нужен. Язык подписей в растровых тайлах задаётся поставщиком; для полного контроля языка позже понадобится отдельный векторный слой. Перед публикацией потребуется настроить авторизацию домена у поставщика карты.

Это результат первого этапа. Фильтры, исторический поиск, кластеризация и воспроизведение относятся к следующим этапам.
