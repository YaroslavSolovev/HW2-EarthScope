# EarthScope

Учебный React + Vite проект для просмотра природных событий.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно http://127.0.0.1:5173/).

Сейчас загружаются землетрясения USGS M4.5+ за сутки и события NASA EONET за 7 дней. События показаны на карте точками и полигонами; нажатие на элемент списка перемещает карту к событию. Карта использует тёмные тайлы Stadia Maps Alidade Smooth Dark. Если они не загрузятся, автоматически включится OpenStreetMap. Для локальной разработки ключ Stadia не нужен. Язык подписей в растровых тайлах задаётся поставщиком; для полного контроля языка позже понадобится отдельный векторный слой. Перед публикацией потребуется настроить авторизацию домена у поставщика карты.

Исторический поиск, фильтры, кластеризация и воспроизведение пока не реализованы.
