# EarthScope

Учебный React + Vite проект для просмотра природных событий.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно http://127.0.0.1:5173/).

Для проверки: `npm test`, `npm run lint`, `npm run build`.

## Что работает

- Live: последние 24 часа, 7 или 30 дней; ручное обновление и автоматическое обновление раз в 2 минуты.
- History: поиск по USGS и NASA EONET за выбранные даты UTC (до 90 календарных дней).
- Фильтры по категориям NASA, землетрясениям, названию/региону, магнитуде USGS и статусу NASA.
- Карта с точками, полигонами и группировкой близких точек. Список показывает по 50 событий за раз без потери остальных данных.
- Карточка события с датами наблюдений, источником и известными характеристиками.

Землетрясения загружаются с порогом M4.5+. Исторические запросы разбиваются на небольшие интервалы; повторяющиеся записи объединяются по ID с сохранением датированных геометрий. Если один источник недоступен, ошибка показывается отдельно, а второй источник продолжает работать. Исторический архив NASA может быть неполным для отдельных категорий и периодов.

В правом верхнем углу карты можно сравнить пять подложек: яркую Alidade Bright, природную Outdoors, рельефную Stamen Terrain, акварельную Stamen Watercolor и спокойную Alidade Smooth. Если тайлы выбранной карты не загрузятся, автоматически включится OpenStreetMap. Для локальной разработки ключ Stadia не нужен. Язык подписей в растровых тайлах задаётся поставщиком; для полного контроля языка позже понадобится отдельный векторный слой. Перед публикацией потребуется настроить авторизацию домена у поставщика карты.
